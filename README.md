# Weekly Instagram Post Generator for Rumah123

## Overview
This project demonstrates an AI-powered workflow that automatically generates weekly Instagram captions for Rumah123 using the latest property news.

The goal is to reduce manual copywriting while maintaining Rumah123's brand voice:
- Professional
- Trustworthy
- Relatable
- Engaging

## Features
- Retrieve latest property news
- AI-generated Instagram captions
- Auto-generated hashtags
- Call-to-action generation
- Human review before publishing

AI Model: OpenAI GPT-5.5

Workflow Description:

The workflow starts with the latest property topic or news.
GPT-5.5 generates an Instagram caption aligned with Rumah123's brand identity.
The generated content includes a hook, emojis, CTA, and relevant hashtags.
The caption is saved as a draft in Google Docs.
The marketing team reviews and approves the content.
The approved post is published on Instagram.
